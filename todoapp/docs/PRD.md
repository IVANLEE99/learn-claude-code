# 产品需求文档 (PRD) -- Todo App

> 版本：1.0
> 日期：2026-05-11
> 作者：product-manager

---

## 1. 产品概述

### 1.1 产品定位
一款简洁高效的待办事项管理应用，面向个人用户，帮助用户快速记录、分类和管理日常待办任务。

### 1.2 目标用户
- 需要日常任务管理的个人用户
- 希望轻量化、无干扰的待办工具使用者
- 移动端优先的用户群体

### 1.3 核心价值
- 极简操作：3 秒内完成一条待办的创建
- 清晰分类：通过列表组织待办，一目了然
- 状态驱动：聚焦"未完成"，完成后自动归档

## 2. 功能列表

### F01 -- 用户注册与登录
- **用户故事**：作为用户，我希望注册账号并登录，以便我的待办数据在不同设备间同步。
- **验收标准**：
  - 支持邮箱 + 密码注册
  - 支持邮箱 + 密码登录
  - 登录成功后返回 JWT Token
  - 未登录时仅展示公开页面，访问受保护路由时重定向到登录页
- **MVP**：✅ 本期实现

### F02 -- 待办列表管理
- **用户故事**：作为用户，我希望创建不同的待办列表（如"工作"、"生活"），以便按场景分类管理任务。
- **验收标准**：
  - 支持创建列表（名称、颜色标识）
  - 支持重命名列表
  - 支持删除列表（同时删除列表下所有待办）
  - 左侧导航展示所有列表
  - 每个列表显示未完成待办数量
- **MVP**：✅ 本期实现

### F03 -- 待办事项 CRUD
- **用户故事**：作为用户，我希望在列表中添加、编辑、完成和删除待办，以便追踪每项任务的进展。
- **验收标准**：
  - 支持新增待办（标题、可选描述、所属列表、优先级）
  - 支持编辑待办标题和描述
  - 支持标记完成 / 取消完成
  - 支持删除待办
  - 支持设置优先级（高 / 中 / 低）
  - 待办按优先级排序展示
- **MVP**：✅ 本期实现

### F04 -- 待办筛选与搜索
- **用户故事**：作为用户，我希望快速筛选出特定状态的待办，以便聚焦当前需要处理的任务。
- **验收标准**：
  - 支持"全部 / 未完成 / 已完成"筛选
  - 支持按关键词搜索待办标题
  - 筛选状态在 URL 中体现（可分享 / 刷新保持）
- **MVP**：✅ 本期实现

### F05 -- 用户信息管理
- **用户故事**：作为用户，我希望查看和修改我的个人信息，以便保持账号信息准确。
- **验收标准**：
  - 查看当前用户信息（邮箱、昵称、注册时间）
  - 修改昵称
  - 修改密码（需验证旧密码）
- **MVP**：✅ 本期实现

### F06 -- 待办到期提醒
- **用户故事**：作为用户，我希望为待办设置截止日期，以便在到期前收到提醒。
- **验收标准**：
  - 为待办设置截止日期
  - 到期当天在待办卡片上显示"已到期"标识
- **MVP**：❌ 不做（后续版本通过推送通知实现）

### F07 -- 多人协作
- **用户故事**：作为用户，我希望与他人共享列表并分配任务，以便团队协作。
- **验收标准**：共享列表、分配任务、实时同步
- **MVP**：❌ 不做

### F08 -- 数据导出
- **用户故事**：作为用户，我希望导出我的待办数据，以便备份或迁移。
- **验收标准**：导出为 JSON/CSV 格式
- **MVP**：❌ 不做

## 3. 非功能性需求

### 3.1 性能
- 首屏加载时间 < 2 秒（3G 网络）
- API 响应时间 < 500ms（P95）

### 3.2 安全
- 密码使用 bcrypt 加盐哈希存储
- JWT Token 有效期 7 天，支持刷新
- 所有 API 接口需鉴权（除注册/登录外）
- 防止 SQL 注入、XSS 攻击

### 3.3 兼容性
- 移动端优先，响应式设计
- 支持 iOS Safari / Android Chrome / 桌面 Chrome / Firefox / Safari 最新两个版本
- 最小视口宽度 320px

### 3.4 可用性
- 界面语言：中文
- 支持暗色模式
- 可点击区域最小 44px（移动端）
- 表单提供即时校验反馈
