# 二、为什么必须多搜索源

单个 MCP 无法解决所有问题。

| 工具 | 作用 | 缺点 |
|---|---|---|
| Tavily | AI 搜索、Research | 免费额度有限 |
| Brave | 普通网页搜索 | 内容提取弱 |
| Exa | Semantic Search | 偶尔不稳定 |
| Firecrawl | 网页正文提取 | 不负责搜索 |
| Jina Reader | 清洗网页 | 不负责搜索 |
| SearXNG | 免费聚合搜索 | 结果质量波动 |

所以：

# 最佳方案一定是：
## “搜索 + 抓取 + 清洗 + fallback”

# 四、Claude Code 推荐配置

文件：

```txt
~/.claude.json
```

配置：

```json
{
  "mcpServers": {
    "brave": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-brave-search"
      ],
      "env": {
        "BRAVE_API_KEY": "YOUR_KEY"
      }
    },

    "tavily": {
      "command": "npx",
      "args": [
        "-y",
        "tavily-mcp"
      ],
      "env": {
        "TAVILY_API_KEY": "YOUR_KEY"
      }
    },

    "exa": {
      "command": "npx",
      "args": [
        "-y",
        "exa-mcp-server"
      ],
      "env": {
        "EXA_API_KEY": "YOUR_KEY"
      }
    },

    "firecrawl": {
      "command": "npx",
      "args": [
        "-y",
        "firecrawl-mcp"
      ],
      "env": {
        "FIRECRAWL_API_KEY": "YOUR_KEY"
      }
    }
  }
}
```
