# 可信度 · 语气 · 灰色渠道（v3.4）

> Phase 1 选材 + Phase 2 口播共用。枚举禁止自创。

---

## 1. 可信度五档（强制）

| 标签 | 何时用 | 口播示例 |
|------|--------|----------|
| **官方确认** | 官网 / 官方博客 / 官方公告 / 官方账号 | 「官方已确认」 |
| **媒体报道** | 主流科技媒体，尚未官宣 | 「据媒体报道，尚未官宣」 |
| **社区实测** | 用户可复现测试 / 截图实测 | 「社区实测显示」 |
| **源码迹象** | 模型列表 / changelog / 接口字符串 | 「接口里出现了…，不等于发布」 |
| **未确认传闻** | 网传 / 疑似 / 爆料 / 猜测 | 「目前仍是未确认传闻，建议等官宣」 |

**硬规则：**

- 每条新闻 / 每个趋势段必须有且仅有一档  
- `未确认传闻` / `源码迹象` **禁止**确定语气（「已经发布」「官方降智」「铁板钉钉」）  
- 上游报告已有 `可信度：…` 时，视频侧 **沿用**，不得擅自升级档位

## 2. 情绪词黑名单 → 替换

| 禁用/慎用 | 替换 |
|-----------|------|
| 炸了 / 炸裂 / 杀疯了 / 彻底炸锅 | 发布 / 大幅更新 / 引发关注 |
| 翻车 | 故障 / 策略调整 / 体验下降 |
| 大瓜 / 吃瓜 | 争议 / 焦点事件 |
| 闹鬼 | 指标异常 / 疑似灰度 |
| 背刺 | 套餐调整 / 权限收紧 |
| 赢麻 / 红温 | 领先 / 舆论反弹 |
| 白嫖 / 薅羊毛 | 低价渠道风险 / 额度套利风险 |
| 偷家 / 打脸 | 竞争动作 / 前后表述不一致 |
| 震惊 / 不看后悔 | （删除，改写标题） |

**说人话仍可用**：说白了、重点是、对开发者来说、简单说。  
**网感放 Hook**，结论句保持冷静。

## 3. 灰色渠道配额与措辞

### 命中关键词（任一）

封号、KYC、二验、土区、尼区、菲区、印区、反代、中转站、号池、号商、白嫖、薅羊毛、低价订阅、共享账号、接码、代充、求号、出号

### 配额

- **每期视频最多 1 条** 灰色渠道 / 账号权益类独立段落  
- 其余：去掉，或合并为一句带过  
- **禁止**：教具体绕法、推荐接码渠道、教怎么买低价区  

### 统一改写框架

```text
What：平台风控 / 订阅策略发生了什么（事实）
So What：账号与订阅资产风险上升
Now What：走官方渠道、少共享、备份重要数据；不展开灰产操作
可信度：…
```

## 4. 标题专业化（示例）

| 原标题 | 建议标题 |
|--------|----------|
| Codex闹鬼了 | Codex 指标异常：疑似灰度新模型 |
| GPT变VIP | GPT 分阶段开放：访问权限收紧 |
| Claude疯狂封号 | Claude 风控升级：账号资产风险上升 |
| Cursor背刺 | Cursor 套餐调整：前沿模型门槛提高 |
| AI圈今天彻底炸锅 | {事件}：开发者该关注的三个变化 |

---

## 5. 传闻跟踪（Phase 1）

同一未确认事件（如某模型灰度）若 **前 3 天已报且无新事实** → 默认不单独成段，或改为「状态更新一句」。

---

## 6. Phase 2 默认骨架（与 3W）

```text
标题：{事件+影响，无黑名单词}
Hook：{5s 钩子 → 下一句必须落到事实}
每条：
  What：一句可验证事实
  So What：对用户/开发者/行业
  Now What：是否跟进 + 建议
  可信度：{五档}
专业锚点：{eligible script}
CTA
```

精简模式：同样 3W，字数更短，条数 3–5，CTA 可省。
