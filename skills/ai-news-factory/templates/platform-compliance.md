## 1. 选题两档（Phase 1 强制）

### A 档 · 默认可进视频 + 公众号 + 视频号

- 模型 / 产品正式发布、changelog、官方定价
- 开发者工具、开源项目、SDK、评测（社区实测且不编造）
- 公司产品功能上线（如移动端 App），避免融资内幕口吻

### B 档 · 默认 **不进公众号 / 视频号 / 抖音主标题**（可留在 linuxdo 日报 md；B站可弱化保留）

- 融资、IPO、估值、裁员、并购传闻
- 「内部发言外泄」「据传暂停融资」等非官方一手
- 监管、政策联署、白宫/政府、开源是否被「切断/封禁」的对抗叙事
- 地缘、供应链、舆论站队
- 账号灰产、绕区、接码、代充（另见灰色渠道配额）
- **网络安全事故攻击动词作主叙事**（v3.14）：沙箱逃逸、入侵、窃取、横向移动、越狱、零日、黑了
- **立法/两党/终止开关** 等政策立法词作**标题主卖点**（口播可产品化改写，不可当抖音/视频号标题钩子）

**硬规则：**
- 日报/周报视频若必须提 B 档：整期 **≤1 条**，且标题 **禁止**出现 B 档关键词；口播必须「据××报道，未独立核实」或改成产品向（权限/隔离/评测加固）
- 公众号图文：**默认删除全部 B 档**；宁可少写 1–2 条
- 视频号/抖音描述/短标题：**禁止**「切断、外泄、博弈、风暴、同日升温、逃逸、入侵、窃取、立法、两党、终止开关」等
- **B站** 对科技解读通常更宽，仍建议标题弱化攻击动词，避免全平台同一敏感标题

## 2. 公众号专项（《互联网用户公众账号信息服务管理规定》）

### 2.1 高风险条款（删文时优先对照）

| 条款 | 要点 | 本期如何规避 |
|------|------|----------------|
| **第五条** | 提供互联网**新闻信息**服务须许可 | 账号定位改为「产品与开发者观察笔记」，避免「每日要闻/采编」 |
| **第十八条（三）** | 未经许可提供新闻采编发布 | 少用通稿体；多写「个人阅读笔记/产品体验」 |
| **第十八条（六）** | 编造虚假信息、不实来源、误导公众 | 标题勿把媒体报道写成定论；正文标来源与未核实 |
| **第十六条** | 全过程内容安全审核 | Phase 2 必须落盘审核清单 |
| **第四条** | 正确导向 / 清朗空间 | 避免对立叙事与煽动性标题 |

### 2.2 公众号标题/正文禁区词（非穷尽）

`同日升温` `博弈` `切断` `封杀` `外泄` `内幕` `风暴` `炸锅` `铁证`  
`沙箱逃逸` `逃逸` `入侵` `窃取` `横向移动` `终止开关` `两党` `越狱`  
以及：把未官宣融资写成「正式宣布暂停」等过硬句。

### 2.3 更稳的公众号写法

- 标题只保留 **可核验产品事实**（例：`Claude Opus 5 发布：性能与定价怎么看｜今日羊报AI`）
- 导语避免「X 条重磅新闻一次看完」
- 媒体内容：`据××报道（未独立核实）`
- 文末弱化强 CTA；可保留轻量关注句
- 简介/账号介绍避免「新闻/资讯采编」

## 3. 视频号专项（《常见不合规频道内容概述》+ 运营规范）

### 3.1 2026-07-26 高概率命中（限流但无细码时）

| 优先级 | 类型 | 概述条目 | 表现 |
|--------|------|----------|------|
| 1 | AI 真人感主播封面/画面 | **2.x 肖像等** / **9 虚假内容** | 合成主播像真实出镜新闻 |
| 2 | 政策/融资/对抗话术 | **5.9 / 9.x** 等兜底 | Hook「切断」、融资外泄 |
| 3 | 诱导关注评论 | **6 诱导内容** | 通常次要，叠加加分 |
| 4 | 未显著 AI 标识 | 运营规范 AI 生成条款 | 发布页务必打开标识 |

### 3.2 封面铁律（视频号 + 建议全平台）

- 🚫 写实真人主播、假演播室新闻脸（易肖像/虚假）
- ✅ 抽象芯片 / 产品 UI / logo 拼贴 / 纯信息卡片
- ✅ 右上角品牌字 + 底部日期可保留
- 🔴 生成封面 prompt **禁止** `male/female news anchor` 写实人像（v3.13 起）

### 3.3 口播/描述

- 必须可打开 **AI 生成内容标识**
- 短标题 ≤16 字且中性产品向
- 音画相关；禁止文不对题夸张标题

### 3.4 抖音专项（v3.14 / 2026-07-26 周报实测）

| 平台提示 | 含义 | 常见根因 |
|----------|------|----------|
| **不适宜公开** | 比限流更重，几乎不可分发 | 标题主卖点 = 逃逸+立法 / 攻击动词 |
| **限制自己可见** + 违规「**画面**」 | 机审标的是**成片帧**，不是标题 | 场景图仍含隔离舱破裂、入侵、security breach |

**铁律：**
1. 抖音标题/描述与视频号共用 **产品向** 禁词表（见 §1 B 档 + §8）
2. **只改标题/封面不够**：若标签含「画面」，必须 **重画场景图 + 改口播 + 重渲 mp4** 再发
3. 禁止挂无关热门话题叠加科技内容
4. 自主声明：个人观点；有 AI 生成声明则勾选

## 6. 被处置后的处理建议

| 平台 | 常见结果 | 动作 |
|------|----------|------|
| 视频号 | 限制传播 + 敏感或违规 | 换无真人封面 + 中性标题重发；可申诉但预期低 |
| 抖音 | 不适宜公开 / 仅自己可见 | 看违规标签：标题→改文案；**画面**→必须重渲成片 |
| 公众号 | 接投诉删除 + 管理规定 | 接受删除；纯产品向重写；勿同题立即重发 |
| 三者 | 无细码 | 按本模板 A/B 档与封面/画面铁律整改，不赌申诉 |

### 6.1 过审重渲协议（v3.14 · 画面/攻击词命中时强制）

当抖音/视频号因 **画面** 或 **逃逸/立法类标题** 被处置时，**禁止**只改 `publish.json` 标题后重传旧 mp4。

1. 写 `scripts/voiceover-texts-safe.json` + `script-safe-*.md`（禁词表见 §8）  
2. 写 `prompts/image-prompts-safe.json`，**全量或至少高风险 scene 重画**  
3. 重跑 TTS → captions → Composition 时长 → Remotion  
4. 产出 `*-safe.mp4` + `platform-copy-safe.md`（抖音/视频号可复制标题描述）  
5. 封面用无攻击视觉版本；旧敏感成片归档，**勿再发**  
6. 内部审核清单通过 ≠ 平台过审；平台侧必须再扫 §8 禁词 + 场景 Prompt  

**2026-W29 实测：** 改标题后仍「限制自己可见 / 画面」→ 全 8 场景重画 + 口播去敏感词 + 136s 过审成片。

## 8. 抖音 / 视频号 / 公众号标题禁词表（v3.14，主标题禁用）

**攻击/安全事故：** 逃逸、沙箱逃逸、入侵、窃取、横向移动、越狱、零日、黑了、突破隔离  
**立法/政治钩子：** 立法、法案、两党、终止开关、白宫（作标题主词时）  
**对抗/内幕：** 切断、外泄、博弈、风暴、同日升温、硬新闻（作标题前缀时慎用）  

**推荐替换（产品向）：**  
评测安全升级 / 权限与隔离 / 安全边界讨论 / 订阅变化 / Flash 全量 / 工具入口 / 一周要闻  

**允许在正文弱化出现、禁止作标题主卖点：** 沙箱（可说「评测环境隔离」）、版权和解（可说「行业版权进展」）。
