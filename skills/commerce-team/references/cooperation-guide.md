# 合作谈判指南

## 全流程概览

```
初步接触 → 信任建立 → 方案设计 → 谈判签约 → 交付留存
```

## 阶段1：初步接触

### 目标
判断这个合作值不值得谈。

### 动作
- 了解对方背景：行业、规模、需求
- 评估合作价值：收益、资源、成长空间
- 初步判断：值得深入 vs 礼貌拒绝

### 输出
合作意向评估报告

### 评估维度

| 维度 | 评估标准 |
|------|----------|
| 行业匹配 | 对方行业是否在你的能力范围内 |
| 需求清晰 | 对方是否明确知道自己要什么 |
| 预算合理 | 对方预算是否匹配你的报价 |
| 成长空间 | 合作是否有长期发展潜力 |
| 资源互补 | 双方资源是否能互相赋能 |

## 阶段2：信任建立

### 目标
让对方相信你能接住这件事。

### 四层信任打透

1. **流量层**：展示专业能力
   - 发布行业相关内容
   - 展示过往案例和作品
   - 分享行业洞察和观点

2. **转化层**：建立私域信任
   - 加微信，保持沟通
   - 朋友圈展示专业人设
   - 及时回复，展现靠谱

3. **关键动作**：
   - 用内容证明"我懂这个行业"
   - 用沟通证明"我靠谱、有节奏"
   - 用案例证明"我接得住这件事"

### 输出
信任背书材料包（案例集、作品集、资质证明）

## 阶段3：方案设计

### 目标
设计合作架构，让对方看到清晰的合作路径。

### 合作架构选项对比表

| 合作模式 | 优势 | 风险 | 适合场景 |
|----------|------|------|----------|
| 固定费用 | 收益确定 | 可能低估价值 | 需求明确 |
| 分成模式 | 收益上限高 | 收益不确定 | 效果可量化 |
| 股权合作 | 深度绑定 | 流动性差 | 长期合作 |
| 混合模式 | 平衡风险 | 复杂度高 | 大型项目 |

### 输出
合作架构选项对比表（每种模式的风险和收益讲清楚）

## 阶段4：谈判签约

### 目标
达成共识，签订MOU/合同。

### MOU/合同核心条款

1. **合作范围**：做什么、不做什么
2. **交付标准**：交付什么、什么时间、什么质量
3. **付款方式**：多少钱、分几期、什么时候付
4. **双方权责**：谁负责什么、怎么配合
5. **违约条款**：违约怎么处理
6. **资源对接**：未来怎么互相对接资源

### 输出
MOU/合同草案

### 注意事项
- 提前说好"未来怎么互相对接资源"
- 明确交付标准和验收方式
- 付款节点与交付节点挂钩
- 保留必要的修改和退出机制

## 阶段5：交付留存

### 目标
按约定交付，维护长期合作关系。

### 动作
- 按约定时间和质量交付
- 定期沟通进展，保持透明
- 主动解决问题，不推诿
- 交付后回访，了解满意度
- 维护关系，争取长期合作

### 输出
项目复盘报告

## 核心难点

> 一个二十年的老厂，对面是一个程序员一人公司——他凭什么相信你？

**凭的就是四层把信任一层一层打透：**

1. 流量层：先在内容上证明"我懂这个行业"
2. 转化层：把私域聊天的信任浓度做出来
3. 成交层：在合作架构选项对比表里把每种模式的风险和收益讲清楚
4. 留存层：提前说好"未来怎么互相对接资源"

**最难的从来不是技术——是让一个二十年的老厂愿意相信一个一人公司能接住这件事。**
