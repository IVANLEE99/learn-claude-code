# 四层漏斗模板

## 核心模型

```
流量是流量，钱是钱。中间隔着四层：

流量层  →  转化层  →  成交层  →  留存层
让人看到你  让人信你  让人买你  让人复购你
```

## 第一层：流量层 — 让人看到你

### 目标
精准流量，不是泛流量。

### 策略
- 内容引流：自媒体团队负责生产内容
- 精准触达：针对目标用户群体
- 持续输出：保持内容频率和质量

### 关键指标
- 曝光量
- 点击率
- 关注转化率

### 核心动作
持续输出有价值的内容，让人主动找到你。

## 第二层：转化层 — 让人信你

### 目标
把陌生人变成信任你的人。

### 策略
- 私域沉淀：引导加微信、进社群
- 信任培育：朋友圈人设、社群互动、1对1沟通
- 价值输出：持续提供有用的内容和帮助

### 关键指标
- 加微率
- 互动率
- 信任度

### 核心动作
把私域聊天的信任浓度做出来。

## 第三层：成交层 — 让人买你

### 目标
把信任变成付费。

### 策略
- 产品推荐：匹配用户需求的合适产品
- 成交场景：社群发售、私信成交、直播带货
- 价格锚定：先展示高价，再展示实际价格

### 关键指标
- 转化率
- 客单价
- 首购率

### 核心动作
在合适的时机，用合适的方式，推荐合适的产品。

## 第四层：留存层 — 让人复购你

### 目标
一次成交变长期关系。

### 策略
- 售后服务：超出预期的交付体验
- 复购引导：会员体系、阶梯产品、老客户专属
- 裂变机制：老带新、口碑传播

### 关键指标
- 复购率
- LTV（用户终身价值）
- 转介绍率

### 核心动作
让客户觉得值，愿意再来，愿意推荐。

## 四层漏斗诊断表

| 层级 | 诊断问题 | 健康标准 | 优化方向 |
|------|----------|----------|----------|
| 流量层 | 有多少人看到你？ | 日曝光1000+ | 内容质量、投放策略 |
| 转化层 | 多少人信任你？ | 加微率10%+ | 人设打造、信任培育 |
| 成交层 | 多少人付费？ | 转化率5%+ | 产品匹配、成交话术 |
| 留存层 | 多少人复购？ | 复购率30%+ | 售后服务、会员体系 |

## 外部客户合作的四层应用

当有外部客户找上门谈合作时，四层漏斗同样适用：

1. **流量层**：让对方看到你的专业能力（内容、案例、作品）
2. **转化层**：把聊天的信任浓度做出来（专业、靠谱、有节奏）
3. **成交层**：在合作架构选项对比表里把每种模式的风险和收益讲清楚
4. **留存层**：提前说好"未来怎么互相对接资源"

**核心难点**：最难的从来不是技术——是让对方愿意相信你能接住这件事。
