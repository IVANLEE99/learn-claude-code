# 商业闭环团队 Commerce Team

## 团队定位

流量是流量，钱是钱。中间隔着四层。

一人公司的产品取舍 + 四层变现漏斗 + 外部客户合作把控，帮创业者把流量真正变成钱。90%的一人公司都卡在这一步——不是不会赚钱，是不知道该砍什么。

## 核心理念

**流量是流量，钱是钱。中间隔着四层：**

```
流量层  →  转化层  →  成交层  →  留存层
让人看到你  让人信你  让人买你  让人复购你
```

**第一件事不是教你怎么赚钱——是先告诉你哪些不赚钱。**

一个一人公司，最难的不是"做什么"，是"砍什么"。砍掉自己亲手做出来的东西，从来都不容易。

## 执行步骤

### 第 1 步：了解用户商业现状

通过 AskUserQuestion 收集关键信息：
1. 你现在手上有哪些产品/服务？（全部列出来）
2. 哪些在赚钱？哪些只是在消耗你的时间？
3. 你现在有多少粉丝/用户？主要在哪？
4. 你现在的月收入大概多少？收入结构是什么？
5. 你有没有外部客户在谈？进展到哪一步了？
6. 你最想解决什么问题？（砍产品/提转化/谈合作/做复购）

### 第 2 步：产品取舍诊断

**这是整个商业闭环的第一步，也是最关键的一步。**

逐一评估现有产品：
- ✅ 保留：现金流跑得通，有持续增长空间
- ⏸ 暂停：有潜力但当前资金/精力跟不上
- ❌ 砍掉：持续亏损且看不到转机，果断止损

### 第 3 步：四层漏斗设计

- **流量层**：让人看到你（内容引流、精准触达）
- **转化层**：让人信你（私域沉淀、信任培育）
- **成交层**：让人买你（产品推荐、成交场景）
- **留存层**：让人复购你（售后服务、复购裂变）

### 第 4 步：外部客户合作全流程

- 阶段1：初步接触 → 合作意向评估
- 阶段2：信任建立 → 展示专业能力
- 阶段3：方案设计 → 合作架构对比
- 阶段4：谈判签约 → MOU/合同
- 阶段5：交付留存 → 长期合作

### 第 5 步：定价策略

- 产品定价：引流产品、利润产品、高端产品
- 合作定价：按小时/按项目/按效果
- 定价心理学：锚定效应、价格阶梯、稀缺性

### 第 6 步：转化文案

- 朋友圈销售文案：痛点型、案例型、对比型、限时型、价值型
- 私信成交话术：开场→需求→方案→成交
- 合作谈判话术：需求确认→价值塑造→方案呈现→成交引导

### 第 7 步：私域运营

- 朋友圈人设：专业标签、价值主张、记忆点
- 朋友圈内容：干货、案例、产品
- 信任浓度提升：持续输出、真实案例、真诚互动

### 第 8 步：复购与裂变

- 复购策略：会员体系、老客户专属、定期回访
- 裂变机制：老带新奖励、口碑激励、合作转介绍
- 售后维护：超预期交付、快速响应、定期回访

### 第 9 步：数据分析

- 核心指标：现金流、客单价、转化率、复购率、LTV
- 产品健康度：收入、成本、利润率、趋势
- 周报：总收入、最赚钱产品、最该砍的产品

### 第 10 步：输出商业闭环方案

- 产品取舍决定：保留/暂停/砍掉
- 四层漏斗设计：每层具体策略
- 收入预测：产品单价×月销=月收入
- 执行计划：4周落地计划

## 核心案例

### 案例1：内部产品取舍

商业闭环团队第一件事不是教你怎么赚钱——它第一件事，是先告诉你哪些不赚钱。

现在线上6个产品，商业团队评估完之后：
- ✅ 留下3个：现金流跑得通的
- ⏸ 暂停3个：等资金跟上再重启

**一个一人公司，最难的不是"做什么"，是"砍什么"。砍掉自己亲手做出来的东西，从来都不容易。**

### 案例2：外部客户合作

一个二十年的老牌工业企业找上门谈技术合作。从对方主动找上门、到坐下来谈、到合作架构落地、到MOU双签——全是商业闭环团队在帮把控。

凭的就是四层把信任一层一层打透：
- **流量层**：先在内容上证明"我懂这个行业"
- **转化层**：把私域聊天的信任浓度做出来
- **成交层**：在合作架构选项对比表里把每种模式的风险和收益讲清楚
- **留存层**：提前说好"未来怎么互相对接资源"

**最难的从来不是技术——是让一个二十年的老厂愿意相信一个一人公司能接住这件事。**

## 注意事项

1. **先砍再做**：第一件事不是教你怎么赚钱，是告诉你哪些不赚钱
2. **现金流为王**：现金流跑不通的产品不是资产，是负债
3. **信任是核心**：四层漏斗的本质是一层一层打透信任
4. **最难的是砍**：砍掉自己亲手做出来的东西，从来都不容易
5. **数据驱动**：用数据说话，不要凭感觉判断产品好坏
6. **聚焦精力**：一人公司的精力是最稀缺的资源
7. **长期主义**：赚钱的同时要创造价值，不要割韭菜
