## 一、产品定位

**一句话**：高亮网页文字，一键保存为笔记。

**解决的问题**：
- 看到好文章，想摘录几句，但复制粘贴太麻烦
- 摘录的内容没有来源（URL、标题、时间），事后找不到出处
- 摘录散落在各处，没有统一管理
- 想导出到Notion/Obsidian，但没有好的工具

**核心卖点**：
1. **高亮即保存**：选中文字，一键保存
2. **自动记录来源**：URL、标题、时间，自动记录
3. **导出自由**：Markdown/Notion/Obsidian/JSON

## 五、技术方案

### 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| Chrome插件 | Manifest V3 | 最新标准 |
| 前端框架 | React + TypeScript | 主流 |
| UI组件 | Tailwind CSS | 快速开发 |
| 存储 | Chrome Storage API | 本地存储 |
| 云端同步 | Firebase / Supabase | 可选 |
| 构建工具 | Vite + CRXJS | Chrome插件构建 |

### 核心逻辑

```
用户选中文字
    ↓
Content Script检测到选区
    ↓
出现浮动工具条
    ↓
用户点击"保存"
    ↓
提取选中文字 + 页面元数据（URL、标题、时间）
    ↓
保存到Chrome Storage
    ↓
弹出通知
```

### 核心API

```typescript
// 保存摘录
async function saveClip(clip: {
  text: string;
  url: string;
  title: string;
  folder?: string;
  tags?: string[];
}) {
  const clips = await chrome.storage.local.get('clips');
  clips.clips.unshift({
    ...clip,
    id: Date.now().toString(),
    createdAt: new Date().toISOString(),
  });
  await chrome.storage.local.set({ clips: clips.clips });
}

// 检测选区
document.addEventListener('mouseup', () => {
  const selection = window.getSelection();
  if (selection && selection.toString().trim()) {
    showToolbar(selection);
  }
});
```
