## 一、产品定位

**一句话**：一篇文章，一键改写成任意平台风格。

**解决的问题**：
- 自媒体人需要在多个平台发布内容，每个平台风格不同，手动改写太累
- 同一个内容，改写成小红书、抖音、公众号、B站风格，需要1-2小时
- 不知道每个平台的爆款公式是什么
- 想用AI改写，但不知道怎么写提示词

**核心卖点**：
1. **一键改写**：输入文章，选择平台，一键生成
2. **平台适配**：内置各平台爆款公式和风格模板
3. **批量生成**：一篇文章，同时生成多个平台版本

## 五、技术方案

### 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 前端框架 | React + TypeScript | 主流 |
| UI组件 | Tailwind CSS + shadcn/ui | 快速开发 |
| AI接口 | OpenAI API / Claude API | 改写能力 |
| 状态管理 | Zustand | 轻量 |
| 构建工具 | Vite | 快速 |
| 部署 | Vercel | 免费 |

### 核心逻辑

```
用户输入文章
    ↓
选择目标平台
    ↓
调用AI API，传入：
  - 原文
  - 平台风格模板
  - 爆款公式
    ↓
AI返回改写结果
    ↓
展示结果，支持复制/编辑/导出
```
