## 一、产品定位

**一句话**：不上传服务器，本地清洗你的数据。

**解决的问题**：
- 运营拿到的CSV有乱码、空行、重复数据，手动清理太慢
- 跨境电商需要把平台导出的数据转换成ERP能导入的格式
- 数据分析师需要快速筛选、排序、合并多个数据文件
- 所有人都不想把数据上传到陌生服务器

**核心卖点**：
1. **本地处理**：数据不离开浏览器，隐私安全
2. **零门槛**：打开网页就能用，不用装软件
3. **一键操作**：去重、筛选、转换，点一下就行

## 三、功能设计

### 免费版（引流）

| 功能 | 说明 |
|------|------|
| CSV查看 | 打开CSV文件，表格形式展示 |
| JSON查看 | 打开JSON文件，树形展示 |
| 格式转换 | CSV→JSON、JSON→CSV |
| 基础去重 | 按整行去重 |
| 基础排序 | 按单列排序 |
| 下载结果 | 导出清洗后的文件 |

**限制**：单文件最大1MB，每天最多处理5次。

### Pro版（19.9元买断）

| 功能 | 说明 |
|------|------|
| 全部免费功能 | 无限制 |
| 高级去重 | 按指定列去重 |
| 高级排序 | 多列排序 |
| 筛选过滤 | 按条件筛选行（包含/不包含/正则） |
| 列操作 | 删除列、重命名列、调整列顺序 |
| 批量替换 | 全局替换指定内容 |
| 合并文件 | 多个CSV/JSON合并 |
| 数据统计 | 列的统计信息（数量、去重数、空值数） |

### 高级版（49元买断）

| 功能 | 说明 |
|------|------|
| 全部Pro功能 | 无限制 |
| 正则提取 | 用正则从列中提取内容 |
| 数据透视 | 简单的数据透视表 |
| Excel支持 | 支持.xlsx格式 |
| 批量处理 | 一次处理多个文件 |
| 操作历史 | 撤销/重做操作 |
| 导出模板 | 保存常用清洗流程 |

## 五、技术方案

### 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 前端框架 | React + TypeScript | 主流，生态好 |
| UI组件 | Tailwind CSS + shadcn/ui | 快速开发，好看 |
| 数据处理 | PapaParse (CSV) + SheetJS (Excel) | 成熟库 |
| 状态管理 | Zustand | 轻量 |
| 构建工具 | Vite | 快速 |
| 部署 | Vercel / Netlify | 免费，快速 |

### 核心逻辑

```
用户上传文件
    ↓
本地解析（PapaParse/SheetJS）
    ↓
数据存入内存（不上传服务器）
    ↓
用户选择操作（去重/排序/筛选/替换）
    ↓
本地执行操作
    ↓
预览结果
    ↓
导出文件
```

### 关键代码结构

```
src/
├── components/
│   ├── FileUpload.tsx      # 文件上传组件
│   ├── DataTable.tsx       # 数据表格组件
│   ├── OperationPanel.tsx  # 操作面板组件
│   └── ExportButton.tsx    # 导出按钮
├── utils/
│   ├── csv.ts              # CSV解析/导出
│   ├── json.ts             # JSON解析/导出
│   ├── excel.ts            # Excel解析/导出
│   └── operations.ts       # 数据操作（去重/排序/筛选）
├── stores/
│   └── dataStore.ts        # 数据状态管理
└── pages/
    ├── index.tsx           # 首页
    └── workspace.tsx       # 工作台
```
