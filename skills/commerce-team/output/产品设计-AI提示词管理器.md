> 产品名：PromptBox / 提示词宝箱

---

## 一、产品定位

**一句话**：管理你的AI提示词，一键填入ChatGPT/Claude。

**解决的问题**：
- 每天用ChatGPT/Claude，好用的提示词散落在各处，找不到
- 每次都要重新打字或翻聊天记录复制，浪费时间
- 想分享提示词给朋友，但没有好的管理方式
- 提示词越来越多，没有分类和搜索功能

**核心卖点**：
1. **一键填入**：点一下，提示词直接填入AI对话框
2. **分类管理**：按场景/用途分类，找得到
3. **变量替换**：提示词模板支持变量，一次写好，反复使用

## 五、技术方案

### 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| Chrome插件 | Manifest V3 | 最新标准 |
| 前端框架 | React + TypeScript | 主流 |
| UI组件 | Tailwind CSS | 快速开发 |
| 存储 | Chrome Storage API | 插件本地存储 |
| 云端同步 | Firebase / Supabase | 可选 |
| 构建工具 | Vite + CRXJS | Chrome插件构建 |

### 核心逻辑

```
用户保存提示词
    ↓
存入Chrome Storage（本地）
    ↓
用户打开AI网站
    ↓
插件检测到ChatGPT/Claude页面
    ↓
用户点击提示词
    ↓
脚本找到页面输入框
    ↓
填入提示词（处理变量替换）
    ↓
自动聚焦输入框
```

### 关键代码结构

```
src/
├── popup/                  # 插件弹窗
│   ├── App.tsx
│   ├── PromptList.tsx      # 提示词列表
│   ├── SearchBar.tsx       # 搜索栏
│   └── CategoryNav.tsx     # 分类导航
├── content/                # 内容脚本（注入到AI网站）
│   ├── detector.ts         # 检测当前AI平台
│   ├── filler.ts           # 填入提示词
│   └── chatgpt.ts          # ChatGPT适配
│   └── claude.ts           # Claude适配
├── background/             # 后台脚本
│   └── sync.ts             # 云端同步
├── options/                # 设置页
│   └── Settings.tsx
└── shared/
    ├── storage.ts          # 存储工具
    └── types.ts            # 类型定义
```

### AI平台适配

| 平台 | 输入框选择器 | 填入方式 |
|------|-------------|----------|
| ChatGPT | `#prompt-textarea` | innerHTML + input事件 |
| Claude | `[contenteditable]` | innerHTML + input事件 |
| 文心一言 | `.chat-input` | value + input事件 |
| 通义千问 | `textarea` | value + input事件 |
