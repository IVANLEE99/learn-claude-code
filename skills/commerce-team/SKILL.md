# 商业闭环团队 Commerce Team

流量是流量，钱是钱。中间隔着四层。

一人公司的产品取舍 + 四层变现漏斗 + 外部客户合作把控，帮创业者把流量真正变成钱。90%的一人公司都卡在这一步——不是不会赚钱，是不知道该砍什么。

## 触发条件

当用户提到以下关键词时，自动触发此 Skill：
- 变现 / 赚钱 / 收入 / 商业闭环 / commerce-team
- 产品取舍 / 砍产品 / 哪个赚钱 / 该不该做
- 客户合作 / 谈合作 / 签合同 / MOU / 报价
- 转化率 / 漏斗 / 成交 / 复购
- 定价 / 涨价 / 价格策略
- 私域 / 社群变现 / 咨询服务

## 团队架构（11个agent）

### 核心指挥层（2人）
1. **商业架构师** - 设计整体变现模型，第一件事是告诉你哪些不赚钱
2. **四层漏斗设计师** - 设计流量层→转化层→成交层→留存层的完整路径

### 产品决策层（2人）
3. **产品取舍顾问** - 评估现有产品线，砍掉不赚钱的，聚焦现金流跑得通的
4. **定价策略师** - 产品定价、价格锚定、合作模式设计

### 转化执行层（4人）
5. **转化文案师** - 撰写销售页、朋友圈文案、私信话术
6. **私域运营师** - 朋友圈人设、社群运营、信任浓度提升
7. **成交促进师** - 社群发售、私信成交、直播带货
8. **客户合作顾问** - 外部客户从找上门到签约的全流程把控

### 留存裂变层（3人）
9. **复购运营师** - 会员体系、续费策略、老客户维护
10. **售后维护师** - 客户满意度、口碑传播、转介绍
11. **数据分析师** - 分析变现数据，优化ROI，倒推产品调整

## 核心理念

**流量是流量，钱是钱。中间隔着四层：**

```
┌─────────────────────────────────────────────┐
│                                             │
│  流量层  →  转化层  →  成交层  →  留存层    │
│                                             │
│  让人看到你  让人信你  让人买你  让人复购你  │
│                                             │
└─────────────────────────────────────────────┘
```

**第一件事不是教你怎么赚钱——是先告诉你哪些不赚钱。**

一个一人公司，最难的不是"做什么"，是"砍什么"。砍掉自己亲手做出来的东西，从来都不容易。

## 执行步骤

### 第 1 步：了解用户商业现状

通过 AskUserQuestion 收集关键信息：

```
1. 你现在手上有哪些产品/服务？（全部列出来）
2. 哪些在赚钱？哪些只是在消耗你的时间？
3. 你现在有多少粉丝/用户？主要在哪？
4. 你现在的月收入大概多少？收入结构是什么？
5. 你有没有外部客户在谈？进展到哪一步了？
6. 你最想解决什么问题？（砍产品/提转化/谈合作/做复购）
```

### 第 2 步：产品取舍诊断（产品取舍顾问）

**这是整个商业闭环的第一步，也是最关键的一步。**

根据用户的产品清单，逐一评估：

```
🔪 产品取舍诊断报告：

【现有产品评估】
| 产品 | 月收入 | 月投入时间 | 现金流 | 判定 |
|------|--------|-----------|--------|------|
| 产品A | XX元 | X小时 | 正/负 | ✅保留/⏸暂停/❌砍掉 |
| 产品B | XX元 | X小时 | 正/负 | ✅保留/⏸暂停/❌砍掉 |
| 产品C | XX元 | X小时 | 正/负 | ✅保留/⏸暂停/❌砍掉 |

【判定标准】
✅ 保留：现金流跑得通，有持续增长空间
⏸ 暂停：有潜力但当前资金/精力跟不上，等条件成熟再重启
❌ 砍掉：持续亏损且看不到转机，果断止损

【聚焦建议】
保留产品：[产品列表] - 理由：[为什么这些能活]
暂停产品：[产品列表] - 理由：[缺什么条件]
砍掉产品：[产品列表] - 理由：[为什么必须砍]

【释放资源】
砍掉/暂停后，每月释放 X 小时 + XX 元资金
建议投入到：[具体方向]
```

**核心原则**：
- 不赚钱的产品不是资产，是负债
- 一人公司的精力是最稀缺的资源
- 砍掉是为了让剩下的活得更好

### 第 3 步：四层漏斗设计（四层漏斗设计师）

```
🔄 四层变现漏斗：

【第一层：流量层 — 让人看到你】
目标：精准流量，不是泛流量
- 内容引流：自媒体团队负责生产内容
- 关键指标：曝光量、点击率、关注转化率
- 核心动作：持续输出有价值的内容，让人主动找到你

【第二层：转化层 — 让人信你】
目标：把陌生人变成信任你的人
- 私域沉淀：引导加微信、进社群
- 信任培育：朋友圈人设、社群互动、1对1沟通
- 关键指标：加微率、互动率、信任度
- 核心动作：把私域聊天的信任浓度做出来

【第三层：成交层 — 让人买你】
目标：把信任变成付费
- 产品推荐：匹配用户需求的合适产品
- 成交场景：社群发售、私信成交、直播带货
- 关键指标：转化率、客单价、首购率
- 核心动作：在合适的时机，用合适的方式，推荐合适的产品

【第四层：留存层 — 让人复购你】
目标：一次成交变长期关系
- 售后服务：超出预期的交付体验
- 复购引导：会员体系、阶梯产品、老客户专属
- 裂变机制：老带新、口碑传播
- 关键指标：复购率、LTV、转介绍率
- 核心动作：让客户觉得值，愿意再来，愿意推荐
```

### 第 4 步：外部客户合作全流程（客户合作顾问）

**当有外部客户找上门谈合作时，商业闭环团队帮你把控全流程。**

```
🤝 外部客户合作全流程：

【阶段1：初步接触】
- 对方主动找上门
- 了解对方背景：行业、规模、需求
- 初步判断：这个合作值不值得谈
- 输出：合作意向评估报告

【阶段2：信任建立】
- 流量层：让对方看到你的专业能力（内容、案例、作品）
- 转化层：把聊天的信任浓度做出来（专业、靠谱、有节奏）
- 关键动作：展示你懂这个行业，你接得住这件事
- 输出：信任背书材料包

【阶段3：方案设计】
- 了解对方真实需求和预算
- 设计合作架构选项对比表
- 每种合作模式的风险和收益讲清楚
- 输出：合作架构选项对比表

【阶段4：谈判签约】
- 协助准备MOU/合同条款
- 明确双方权责、交付标准、付款方式
- 提前说好"未来怎么互相对接资源"
- 输出：MOU/合同草案

【阶段5：交付留存】
- 按约定交付
- 定期沟通进展
- 维护长期合作关系
- 输出：项目复盘报告
```

**核心难点**：
> 一个二十年的老厂，对面是一个程序员一人公司——他凭什么相信你？
> 凭的就是这四层把信任一层一层打透。
> 最难的从来不是技术——是让一个二十年的老厂愿意相信一个一人公司能接住这件事。

### 第 5 步：定价策略（定价策略师）

```
💰 定价策略：

【产品定价】
- 引流产品：低价建立信任，9.9-99元
- 利润产品：核心收入来源，199-999元
- 高端产品：提升客单价，1999-9999元
- 超高端：筛选高净值客户，10000元+

【合作定价】
- 咨询服务：按小时/按项目/按效果
- 技术合作：固定费用/分成/股权
- 品牌合作：报价单/打包价/长期协议

【定价心理学】
- 锚定效应：先展示高价，再展示实际价格
- 价格阶梯：低中高三档，引导选中间
- 稀缺性：限时/限量提升紧迫感
```

### 第 6 步：转化文案（转化文案师）

```
✍️ 转化文案：

【朋友圈销售文案】
1. 痛点型："你是不是也遇到过这个问题..."
2. 案例型："XX客户用了这个方法，3天XX"
3. 对比型："合作前vs合作后，差距太大了"
4. 限时型："最后X个名额，错过等下期"
5. 价值型："这套方案价值XX元，今天只要..."

【私信成交话术】
- 开场："你好！看到你关注XX很久了"
- 需求："你目前最大的困惑是什么？"
- 方案："这个问题我可以帮你解决"
- 成交："我们现在有个XX活动，很适合你"

【合作谈判话术】
- 需求确认："您这边最想解决什么问题？"
- 价值塑造："这个问题如果解决，能帮您..."
- 方案呈现："我建议我们这样合作..."
- 成交引导："我们可以先从XX开始，您觉得呢？"
```

### 第 7 步：私域运营（私域运营师）

```
📱 私域运营：

【朋友圈人设】
- 专业标签：[你的专业身份]
- 价值主张：[你能帮别人解决什么]
- 记忆点：[别人记住你的一个点]

【朋友圈内容规划】
| 时间 | 内容类型 | 目的 |
|------|----------|------|
| 早8点 | 干货分享 | 提供价值 |
| 中12点 | 案例/成果 | 建立信任 |
| 晚8点 | 产品/合作 | 促进转化 |

【信任浓度提升】
- 持续输出专业内容
- 展示真实案例和数据
- 分享客户好评和反馈
- 保持真诚，不夸大
```

### 第 8 步：复购与裂变（复购运营师 + 售后维护师）

```
🔁 复购与裂变：

【复购策略】
- 会员体系：积分、等级、专属权益
- 老客户专属：折扣、优先、赠品
- 定期回访：使用反馈、新需求挖掘
- 产品升级：基于反馈迭代产品

【裂变机制】
- 老带新奖励：推荐返现/送服务
- 口碑激励：好评返现、案例征集
- 合作转介绍：老客户推荐新客户

【售后维护】
- 超预期交付：多做一点点
- 快速响应：问题24小时内解决
- 定期回访：主动关心使用情况
- 资源对接：帮客户连接有用资源
```

### 第 9 步：数据分析（数据分析师）

```
📊 变现数据分析：

【核心指标】
| 指标 | 定义 | 健康值 | 优化方向 |
|------|------|--------|----------|
| 现金流 | 收入-支出 | 正数 | 砍掉负现金流产品 |
| 客单价 | 平均每单金额 | 行业1.5倍+ | 提升产品价值 |
| 转化率 | 流量→成交 | 5%+ | 优化四层漏斗 |
| 复购率 | 二次购买比例 | 30%+ | 会员体系 |
| LTV | 用户终身价值 | 客单价x3+ | 提升留存 |

【产品健康度评估】
| 产品 | 月收入 | 月成本 | 利润率 | 趋势 | 判定 |
|------|--------|--------|--------|------|------|
| 产品A | XX | XX | XX% | ↑/↓/→ | 保留/优化/砍掉 |

【周报模板】
📊 本周变现数据：
- 总收入：XX元（环比XX%）
- 现金流：XX元
- 最赚钱产品：[产品名]
- 最该砍的产品：[产品名]
- 下周重点：[具体动作]
```

## 注意事项

1. **先砍再做**：第一件事不是教你怎么赚钱，是告诉你哪些不赚钱
2. **现金流为王**：现金流跑不通的产品不是资产，是负债
3. **信任是核心**：四层漏斗的本质是一层一层打透信任
4. **最难的是砍**：砍掉自己亲手做出来的东西，从来都不容易
5. **数据驱动**：用数据说话，不要凭感觉判断产品好坏
6. **聚焦精力**：一人公司的精力是最稀缺的资源
7. **长期主义**：赚钱的同时要创造价值，不要割韭菜
