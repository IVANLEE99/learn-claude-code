# post-to-img 风格预设

## kawaii-journal（默认）

**一句话**：日系手账 × Q 版仓鼠/白兔 × 奶油纸职场复盘信息图。

### 视觉 DNA

| 维度 | 规格 |
|------|------|
| 画幅 | 横版 16:9（API：`1536x1024`）；竖版备选 `1024x1536` |
| 背景 | 暖奶油米白纸 `#FFF8F0`，轻微纸感，非纯白 |
| 主色 | 草莓粉/珊瑚粉标题与爱心 |
| 辅色 | 蜜桃橙、淡黄、薄荷绿、浅紫卡片 |
| 文字色 | 深灰棕，非纯黑 |
| 线条 | 细手绘描边、统一大圆角卡片 |
| 角色 | chibi 仓鼠（多姿势）+ 可选白兔老师（眼镜+粉领结+教鞭） |
| 装饰 | 手绘心、星、闪光、小花、勾选框、胶带感边框 |
| 气质 | 温柔治愈、自嘲但不丧、励志闺蜜感 |
| 禁止 | 写实、3D、赛博霓虹、暗黑、PPT 模板感、无分区字墙 |

### 布局骨架（写入 prompt）

```
顶栏：左吉祥物+金句气泡 | 中央大标题+副标题 | 右心情清单+吉祥物
中部三栏：
  左 1–3 情绪/现状卡
  中 4 能力表+工具箱 / 5 小尝试
  右 6 计划 / 7 变现或下一步 / 8 给未来的自己
底栏：小贴士 | 全宽寄语 | CTA
```

### 吉祥物 mood → 姿势

| mood | 画面 |
|------|------|
| teacher-rabbit | 白兔戴眼镜粉领结持教鞭 |
| heart | 仓鼠捧粉心 |
| crying | 捂脸哭 |
| sad | 失落低头 |
| dizzy | 晕眩 OO |
| focus-laptop | 戴耳机看笔记本 |
| coins | 捧金币袋 |
| reading | 捧书读 |
| pray | 合掌加油 |
| sweat | 流汗小贴士旁 |

### Prompt 风格段（可直接拼接）

```text
横版日系手账风信息图海报，暖奶油米白纸张背景，草莓粉蜜桃橙薄荷绿低饱和配色。
细手绘描边，平涂淡彩与腮红，圆角贴纸拼贴分区，Q版仓鼠与白兔吉祥物点缀。
高信息密度但透气，深灰棕字，温柔治愈励志，不丧不暗黑。
无写实摄影、无3D、无霓虹赛博、无真人脸、印刷级清晰数字插画。
```

## clean-tech

**一句话**：浅灰蓝极简技术信息卡，无吉祥物。

- 背景 `#F7F9FC`，主色靛蓝 `#3B82F6`，卡片白底细灰边  
- 无仓鼠/爱心；用简单 icon 线框  
- 适合纯架构/工具链总结  

### Prompt 风格段

```text
横版极简科技信息图，浅灰蓝背景，白卡片细灰描边，靛蓝标题，无吉祥物无贴纸，
干净 sans 排版感，扁平 UI 插画，专业冷静，非手账非可爱风。
```

## warm-note

**一句话**：便签拼贴短感想，少表格。

- 多张旋转角度很小的黄/粉便签  
- 1 只仓鼠即可  
- 适合短复盘、金句卡  

### Prompt 风格段

```text
暖色便签拼贴海报，米黄底，粉色与淡黄便签微倾角，手写感标题，
一只Q版仓鼠点缀，少表格多短句，治愈手账风，留白充足。
```
