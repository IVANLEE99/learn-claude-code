# Claude Code Skill 详解：corporate-services

## 一、Skill 是什么

Skill（技能）是 Claude Code 的扩展机制，允许用户定义可复用的专业能力。它比 Command（命令）更强大：

| 特性 | Command | Skill |
|------|---------|-------|
| 调用方式 | 用户手动 `/command` | Claude 自动触发 + 用户手动 |
| 文件结构 | 单个 `.md` 文件 | 目录，含 `SKILL.md` + 参考资料 |
| 典型用途 | 动作型："帮我做 X" | 知识型："知道 X 的最佳实践" |
| 可捆绑资源 | 不能 | 可以（模板、脚本、示例等） |

**一句话理解**：Command 是快捷操作按钮，Skill 是会自动识别场景并执行标准流程的领域专家。

## 二、corporate-services Skill 说明

### 功能

一人公司的企业服务顾问，帮创业者搞定：
- 公司注册流程（线上/线下）
- 经营范围规划（未来 3 年业务边界）
- 公司类型选择（个体户、有限公司、合伙企业等）
- 基础法务知识（合同审查要点、常见法律风险）
- 财税基础（记账报税、发票管理、税种区分）
- 合规检查（资质许可、行业准入）

### 触发条件

当用户提到以下关键词时，自动触发：
- 注册公司 / 开公司 / 创业开公司
- 经营范围 / 营业执照
- 企业服务 / corporate services
- 法务 / 合规 / 财税
- 公司类型选择（个体户 vs 有限公司）
- 代办公司 / 工商注册

### 角色定位

**企业服务顾问**，精通：
- 公司注册流程（线上/线下）
- 经营范围规划（未来 3 年业务边界）
- 公司类型选择（个体户、有限公司、合伙企业等）
- 基础法务知识（合同审查要点、常见法律风险）
- 财税基础（记账报税、发票管理、税种区分）
- 合规检查（资质许可、行业准入）

**风格**：口语化、像朋友聊天，用真实案例和数据说话，避免专业术语堆砌。

## 三、执行流程

```
用户: "我想注册公司"
        ↓
Step 1: 了解用户情况（业务、合伙、城市、营收）
        ↓
Step 2: 公司类型推荐（个体户/一人公司/有限公司/合伙企业）
        ↓
Step 3: 经营范围规划（推荐范围 + 特殊资质提醒）
        ↓
Step 4: 注册流程指引（代办 vs 自己跑 + 省钱技巧）
        ↓
Step 5: 合规检查清单（定制化合规事项）
        ↓
Step 6: 输出总结（费用预估 + 下一步行动）
```

4. **参考链接** — 指向 references 目录的详细文档

## 五、关键风险提示

### 1. 注册资本认缴制已变（最重要！）

**2024年7月新《公司法》已改为5年内实缴**：
- 注册资本 10 万 → 你必须在 5 年内实际缴纳 10 万到公司账户
- 如果写太高，到期缴不上会被追缴+罚款
- **建议写 10 万**，降低实缴压力

### 2. 一人公司"人格混同"举证责任倒置

**一人公司举证责任倒置**：
- 普通公司：债权人需要证明财产混同
- **一人公司：你需要自己证明没有混同**（举证责任倒置）
- 如果证明不了，直接承担连带责任

**必须做到**：
- ✅ 公司账户和个人账户 **100% 分开**
- ✅ 每笔收支都有 **正规发票/合同**
- ✅ 公司的钱不能随意转到个人账户
- ✅ 保留完整的 **财务凭证**

### 3. 一人公司只能开一个

**《公司法》规定**：一个自然人只能投资设立一个一人有限责任公司
- 你不能同时拥有两家一人公司
- 如果想开第二家，必须先加股东变成两人公司

## 九、实际案例

### 案例：广州海珠区软件公司注册

**用户情况**：
- 业务：软件/技术开发
- 形式：个人独立创业
- 注册地：广州海珠区

**输出结果**：
- 公司类型：一人有限责任公司（自然人独资）
- 经营范围：14项一般项目（免费）
- 注册资本：10万（5年内实缴）
- 代办费用：800-2000元
- 办理周期：3-5个工作日

**关键提醒**：
- 5年内需实缴10万
- 每年需做审计（2000-5000元）
- 公司账户与个人账户必须分开
- 零申报不能超过6个月

## 十一、注意事项

1. 本 Skill 提供的是**通用指导**，具体政策以当地工商部门为准
2. 涉及特殊行业资质时，建议咨询专业律师
3. 经营范围变更可以后期办理，不用一开始就写死
4. 一人公司每年需要做审计，这是合规成本
5. 2024年新《公司法》已改为5年内实缴，注意注册资本不要写太高
