# post-to-video 合规检查

> 脚本 / 生图 / 封面 / `publish.json` **强制对照**。结果写入 `{slug}/review-checklist.md`，禁止只口头说「合规」。
> 蒸馏自 `ai-news-factory`（`SKILL.md` 禁止词汇 + 脚本审核清单 + 平台合规审查规则 + `templates/platform-compliance.md` / `credibility-and-tone.md`），并按 **帖子成片** 产品规则改写。
> 改规则前先读 `references/experience.md`。

## **🔴 禁止使用的词汇**

### 来源与社区（本 skill 硬规则，覆盖 factory「佬友→大家」）

| 禁用 | 替换 |
|------|------|
| Linuxdo / linux.do / L站 / Linux.do | **删除**。口播、字幕、画面、封面、简介 **禁止出现帖子来源** |

|-----------|------|

**说人话仍可用**：说白了、重点是、这事儿离谱在哪、简单说。

### 标题 / 短描述禁词（抖音、视频号、公众号主标题禁用）

**允许上封面/标题的冲突词**：认命、靠老人带娃（用户定稿的 Hook 原词）。

### 灰色渠道命中词（任一即占配额）

封号、KYC、二验、土区、尼区、菲区、印区、反代、中转站、号池、号商、白嫖、薅羊毛、低价订阅、共享账号、接码、代充、求号、出号

- 每条视频 **最多 1 处** 带过；**禁止**操作指南、推荐渠道

## **🔴 脚本审核检查清单**

展示脚本 / 进入生图前，必须逐句检查并 **落盘** `{slug}/review-checklist.md`：

1. 禁止词汇 + 情绪黑名单是否清零
2. 来源：口播 / 字幕 / 画面 / 封面 / 简介均无 linux.do、L站、帖子链接、topic 水印
3. 称呼：全部「道友+名字」，无「佬友」裸用、无「各位观众」
4. 口语化、非播音腔；每段 voiceover ≤ 80 字；scenes 顺序 = 播放顺序
5. 不编造：保留原帖金句与事实，可归纳压缩
6. 灰色渠道是否 ≤1 且无操作指南
7. **平台合规审查**（见下方，必须落盘）
8. **Hook / 封面大字（坑 203）**
   - `☐ cover_text` 是 Hook 原词短句两行（1 句冲突 + 1 个数字或判断），**禁止**整条 title 上封面
   - `☐ cover_text` 定稿早于生图；改 Hook 必须重出封面
9. **带娃 / 未成年人**
   - `☐` 不展开虐婴、伤害、犯罪过程
   - `☐` 口播最多点到「新闻太多、不敢交给外人」
10. **画面同步**（只改口播不够）
    - `☐` 分镜 / prompt 无写实儿童主视觉、无虐婴、无血腥、无写实主播
11. **生图出口**
    - `☐` 走 gen-img，不手搓 Images API；日志无 API Key
12. **发布文案**
    - `☐` `publish.json` 已生成；抖音标题 ≤30 字；视频号标题 ≤16 字且无 `.` `~`
13. **帖子内容图（先于视频）**
    - `☐` 4:3 与 3:4 信息图已出，且不是封面、不是分镜
    - `☐` 图内无论坛来源、无写实婴幼儿脸、无伤害画面
    - `☐` 两张 PIL 实测比例通过（竖 ≈0.75 / 横 ≈1.3333；服务端可能不认精确像素，只见比例）
    - `☐` 两张都 `Read` 通过后才进入场景配图 / TTS / 合成

用户已说「直接出片 / 开干」可跳过口头确认，**不能跳过本清单落盘**。

### 🔴 平台合规审查规则

依据仍是四平台公约（与 `ai-news-factory` 相同：B站社区公约、抖音社区自律公约、微信公众平台运营规范、微信视频号运营规范）。本文件是帖子成片的执行版。

### 禁止内容（所有平台通用）

| 类别 | 具体规则 | 本 skill 怎么做 |
|------|---------|----------------|
| 🚫 政治敏感 | 不评论政治事件 | 不写、不画 |
| 🚫 虚假信息 | 不散播谣言、不把网友观点写成定论 | 口播保留「道友××说」；不把评论写成真理 |
| 🚫 暴力恐怖 | 不展示血腥、残忍 | 不描述、不绘制虐婴/伤害细节 |
| 🚫 低俗内容 | 无性暗示 | 不使用低俗用语 |
| 🚫 侵权 | 名誉 / 肖像 / 隐私 / 著作权 | 不写实真人主播封面；不露来源站品牌 |
| 🚫 未成年人 | 不得有损未成年人身心健康 | **允许讨论带娃**；禁止伤害细节与写实儿童主视觉 |

### 标题规范（所有平台通用）

| 规则 | 说明 | 违规示例 |
|------|------|---------|
| 🚫 标题党 | 标题必须与内容相符 | 「震惊！老人带娃内幕」 |
| 🚫 误导性 | 不用侮辱、脏话 | 攻击老人 / 攻击原帖作者 |
| 🚫 文不对题 | 标题与成片一致 | 封面写认命、视频在讲别的 |
| 🚫 来源捆绑 | 标题/封面不出现论坛名 | 「L站热帖」「linux.do」 |

**抖音标题（帖子成片，≠ 日报「报刊名+日期」）**：用书名号标题或封面大字压缩版，**≤30 字**，无 `|` `｜` 硬套新闻报头。

**视频号标题**：≤16 字；符号仅书名号、引号、冒号、加号、问号、百分号、摄氏度；**`.` `~` 不在白名单**。

**B站**：分区按内容选（生活向用「生活」，勿盲填「人工智能」）；简介数字尽量中文化；标签 ≤10，不要被推荐标签污染。

**公众号**：非新闻采编口吻；B 档对抗叙事不上标题。

### 封面铁律（脚本定稿 → 生图 → 叠字）

1. **文字源** = `content.json` 的 `cover_text`（两行），禁止把整条 `title` 印上。
2. **正片只许两张**：`covers/vertical-3-4.png`、`covers/horizontal-4-3.png`。重试底图、无字稿一律进 `covers/.scratch/`，禁止堆在 `covers/` 根目录。
3. **禁止写实真人主播 / 假新闻脸 / 写实婴幼儿照片**。默认 kawaii-journal 插画。
4. API 中文易糊、错字、日文乱码（grok-imagine 实测）→ **先出无字插画，再用 Pillow 本地叠 `cover_text`**（`scripts/overlay_cover_text.py`）。叠完 `Read` 视觉校验，糊字/不居中即重出。
5. 封面 prompt **禁止**要求模型写中文大字（不可靠）；prompt 写 `no text, no letters, no watermark, no website, no forum logo`。

### 生图 / 画面铁律

| 禁止（prompt / 成片） | 改为 |
|----------------------|------|
| 写实儿童、写实婴儿脸特写 | Q 版剪影、背影、手账贴纸风宝宝 |
| 虐婴、伤口、犯罪现场 | 不画；口播也不展开 |
| 写实主播、演播室新闻脸 | 仓鼠/手账吉祥物或纯插画场景 |
| 论坛 UI、linux.do logo、URL | 抽象评论气泡，无站点品牌 |
| 隔离舱破裂、血腥、武器 | 明亮生活场景 |

画质：走 `gen-img`。`gpt-image-2` 预扣费失败（余额 &lt; $1）时改备用端点，**禁止**打印 Key。`grok-imagine-image`：quality 仅 `low`/`medium`；4:3 用 `1536x1024`（`1536x1152` 常拒）。

画面违规（平台标「画面」）必须 **重画 + 改口播 + 重渲 mp4**，禁止只改 `publish.json` 标题重传旧片。

### 各平台特别规则（摘要）

**B站**：禁止低质轮播大字、音画不相关；封面/标题突出违规从重。AI 生成须符合社区规范。

**视频号**：AI 生成内容必须显著标识；封面禁止写实 AI 主播；禁止批量同质化。

**抖音**：禁止借社会负面事件营销；禁止哗众取宠；内部清单通过 ≠ 平台过审。标签含「画面」→ 重渲。

**公众号**：无新闻许可时避免「要闻/采编」体；勿把网友评论写成已核实事实。

### 违规后果

| 平台 | 处罚 |
|------|------|
| B站 | 删除下线、限制传播、封禁 |
| 视频号 | 减少推荐、限制传播、删除、封禁 |
| 抖音 | 删除/屏蔽、暂停功能、封禁 |
| 公众号 | 删除、限制功能、封禁 |
