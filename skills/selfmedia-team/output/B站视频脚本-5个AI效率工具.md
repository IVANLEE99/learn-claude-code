### [00:30-01:15] 工具1：Claude Code

**画面**：Claude Code界面演示
**文案**：
第一个是Claude Code，一个AI编程助手。

它最大的特点是能理解你代码的意图，不只是简单的语法补全。

主要功能有四个：
1. 代码生成：你描述需求，它直接生成完整代码
2. 代码解释：看不懂的代码，让它解释给你听
3. Bug调试：报错信息直接贴进去，帮你分析原因
4. 重构优化：代码写完让它优化，通常能提升20%质量

适合什么场景呢？
- 写重复性代码时，直接描述需求生成
- 接手老项目时，让它解释复杂逻辑
- 调试Bug时，快速定位问题原因

我用了三个月，最明显的感受是写代码的时间减少了40%。以前要查文档、搜Stack Overflow的问题，现在直接问它就行。

### [01:15-02:00] 工具2：Cursor

**画面**：Cursor编辑器演示
**文案**：
第二个是Cursor，一个把AI深度集成到编辑器里的VS Code替代品。

它的核心功能：
1. 智能补全：不是简单的语法补全，而是理解上下文的智能建议
2. 代码重构：选中代码，描述你想怎么改，它帮你重构
3. 多文件编辑：一次对话，同时修改多个相关文件
4. 内联编辑：选中代码，直接用自然语言描述修改需求

适合什么场景呢？
- 重构代码时，让它帮忙批量修改
- 写新功能时，利用智能补全加速
- 代码review时，让它帮忙检查问题

我从VS Code切换到Cursor后，编码速度提升了30%。特别是重构代码的时候，效率提升非常明显。

### [02:00-02:45] 工具3：GitHub Copilot

**画面**：GitHub Copilot演示
**文案**：
第三个是GitHub Copilot，这是我用得最多的工具，已经离不开了。

它的核心功能：
1. 实时补全：写代码时自动给出建议，按Tab接受
2. 函数生成：写好函数名和注释，自动生成实现
3. 测试生成：写好函数，让它帮忙生成单元测试
4. 文档生成：代码写完，自动生成注释和文档

适合什么场景呢？
- 写重复模式的代码时，自动补全超快
- 写单元测试时，让它帮忙生成测试用例
- 写文档时，自动生成规范的注释

这是我每天都在用的工具，每天至少节省2小时。特别是写CRUD代码和单元测试的时候，效率提升巨大。
