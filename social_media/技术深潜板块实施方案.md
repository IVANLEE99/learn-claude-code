# 技术深潜板块实施方案

> 每期 60 秒，从新闻中自然引入 AI 技术概念，提升算法"专业内容"标签。

---

## 一、三种方案对比

| 方案 | 优点 | 致命缺陷 |
|------|------|----------|
| **A. 预设概念列表浅→深** | 系统化，可提前规划 | 和当天新闻脱节，观众感觉在上课，跳出率高 |
| **B. 从当天新闻提取** | 自然融入，看完新闻正好解释 | 有些天全是"封号""涨价"，没有可讲的技术概念 |
| **C. 混合：建立概念库，优先从新闻中提取** | 两者兼顾 | 需要维护一个概念库 |

**推荐方案 C。**

---

## 二、AI 技术概念库

按搜索热度和新闻关联度排序，不是按难度。

### Tier 1 — 高频热搜（观众主动搜）

| 概念 | 一句话解释 | 典型新闻关联 |
|------|------|------|
| MoE（混合专家） | 为什么大模型用它更便宜 | 微软 MAI、DeepSeek、MiniMax |
| Token | 为什么你按 token 付钱 | 任何定价/降价新闻 |
| 上下文窗口 | 为什么 128K 比 8K 贵 10 倍 | GLM-5.2 百万上下文、GPT-5.6 窗口扩大 |
| 蒸馏 | 大模型怎么"抄作业" | Opus 4.8 身份错乱、阿里被指控蒸馏 |
| Agent | AI 怎么自己干活 | Claude Code、Codex、微信 A2A |
| RLHF | 为什么 ChatGPT 不会乱说话 | 安全过滤器争议、Fable 5 太敏感 |
| Fine-tune | 怎么让模型只懂你的业务 | GLM 开源、模型微调排行榜 |

### Tier 2 — 中频（和产品发布强关联）

| 概念 | 一句话解释 | 典型新闻关联 |
|------|------|------|
| RAG | 为什么你的 AI 记不住昨天的事 | 企业 AI 应用、微信小微 |
| 模型量化 | 为什么 4bit 模型能跑在笔记本上 | 本地模型横评、Gemma 4 开源 |
| Diffusion | AI 画图的原理 | 谷歌 Diffusion Gemma、Grok Imagine |
| Attention | 模型怎么"理解"你说的话 | 模型性能对比、降智讨论 |
| Embedding | AI 怎么把文字变成数字 | 语义搜索、RAG 应用 |
| Chain-of-Thought | 为什么"让我想想"能让 AI 更准 | 思考强度设置（xhigh/high/medium） |

### Tier 3 — 低频但有话题性

| 概念 | 一句话解释 | 典型新闻关联 |
|------|------|------|
| Scaling Law | 为什么大厂疯狂烧钱堆参数 | 融资新闻、算力需求 |
| Alignment | AI 为什么有时候拒绝回答 | Claude 安全过滤器、Fable 5 被禁 |
| Constitutional AI | Anthropic 的独门武器 | Anthropic 相关新闻 |
| Mixture of Agents | 多个模型协作 | 多模型横评、编程工具对比 |
| Synthetic Data | AI 用自己生成的数据训练自己 | 蒸馏争议、训练数据讨论 |
| KV Cache | 为什么长对话越来越慢 | Codex 自动压缩、上下文管理 |
| Speculative Decoding | 为什么有些模型特别快 | MiMo UltraSpeed、Cerebras 极速版 |
| Tokenizer | 为什么不同模型数 token 方式不一样 | Sonnet 5 换 tokenizer、token 消耗差异 |

## 三、每天选概念的优先级

```
优先级 1：当天新闻里提到了 → 直接用
  例：6/17 报了"微软 MAI 用 MoE 架构" → 当天深潜讲 MoE

优先级 2：当天新闻没有明显概念 → 从概念库 Tier 1 里挑
  例：6/28 全是封号和低价渠道 → 从库中选"Token 是什么"

优先级 3：热点事件关联概念 → 讲"为什么这件事重要"
  例：Fable 5 被禁 → 讲"什么是出口管制？AI 模型为什么会被禁？"
```

## 四、脚本模板（60 秒）

```markdown
## 技术深潜：什么是 MoE？（60s）

**过渡句（5s）：**
刚才提到微软的 MAI 用了 MoE 架构，MoE 到底是啥？60 秒讲明白。

**类比（15s）：**
想象一家医院有 100 个医生。传统模型是每个病人 100 个医生全看一遍。
MoE 是先来一个分诊台，看你是骨科还是眼科，只派 2 个相关专家来看。
效果差不多，但成本直接砍掉 98%。

**在新闻中怎么体现（15s）：**
微软的 MAI 总参数 1 万亿，但激活参数只有 350 亿。
就是说 1 万亿参数的"知识"都在，但每次只用 3.5% 来回答你。
所以它能接近 Sonnet 4.6 的水平，但推理成本低得多。

**一句话记住（5s）：**
MoE = 大模型的"分诊制度"，省钱不降质。
```

## 五、各概念的类比素材库

| 概念 | 类比 | 来源 |
|------|------|------|
| MoE | 医院分诊台，只派相关专家 | 自拟 |
| Token | 文字的"最小计费单位"，像手机流量的 KB | 自拟 |
| 上下文窗口 | 桌面大小，桌子越大一次能摊开的文件越多 | 自拟 |
| 蒸馏 | 学生抄学霸的作业，抄得像但没学到真本事 | 社区常用 |
| Agent | 请了个助理，你只说目标，它自己规划步骤 | 自拟 |
| RLHF | 训狗——做对了给骨头，做错了不给 | 自拟 |
| Fine-tune | 通才去上了个专业培训班，变成了专科医生 | 自拟 |
| RAG | 给 AI 配了个随身图书馆，不会的现查 | 自拟 |
| 模型量化 | 高清图压缩成缩略图，看着差不多但文件小 10 倍 | 自拟 |
| Diffusion | 先往照片上撒满噪点，再一步步把噪点去掉还原照片 | 技术原理 |
| Attention | 读一句话时眼睛会自动聚焦重点词，忽略"的地得" | 自拟 |
| Chain-of-Thought | 老师说"把解题步骤写出来"，比直接写答案更准 | 自拟 |
| Scaling Law | 10 个人干 1 天的活 ≈ 1 个人干 10 天，但有上限 | 自拟 |
| Alignment | 给 AI 装了个道德指南针，但有时候指南针太敏感 | 自拟 |
| KV Cache | 你翻书做了书签，下次不用从头翻 | 技术原理 |
| Speculative Decoding | 先让实习生快速写个草稿，老师傅再检查修正 | 自拟 |
| Tokenizer | 不同国家切词方式不同——英文按空格，中文按字 | 自拟 |

## 六、和现有脚本的衔接位置

```
Scene 1: Hook（5s）
Scene 2-N: 新闻（每条 12-15s）
  → 技术深潜（60s）← 插在最炸的新闻后面，用那条新闻做引入
Scene N+1: 结尾 CTA（5s）
```

**选哪条新闻后面插入：**
- 优先选有明确技术关键词的新闻（MoE、蒸馏、开源等）
- 避免插在封号/涨价/传闻类新闻后面（没有技术概念可讲）
- 如果当天全是非技术新闻，用"顺便科普一下"的口吻从概念库 Tier 1 中选一个
