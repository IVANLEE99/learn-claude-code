# 用户反馈：AI资讯视频重要程度排序

> 来源：用户评论（2026-06-30）

## 原始评论

> 这种AI资讯视频我一般先让它帮我"按重要程度排个序"，再看就省很多时间。比如先让AI把"GPT变VIP、千问学方言、Codex闹鬼了"压成3条：发生了什么、影响啥、值不值得跟进，脑子一下就清爽了 😆

## 核心需求

1. **重要程度排序**：先按影响力/重要性给所有新闻打分排序，而不是一股脑全上
2. **3 条精华总结**：每条压缩成「发生了什么 → 影响啥 → 值不值得跟进」三段式
3. **减少认知负担**：观众不想看 6-8 条新闻，3-5 条精选就够了

## 建议实现方式

### 可选「精简模式」

- **触发词**：「精简」「排序」「精华版」
- **Phase 1 增加排序步骤**：所有事件按影响力打分（1-5分），展示排序结果
- **Phase 2 脚本压缩**：每条新闻用三段式结构（发生了什么 / 影响啥 / 值不值得跟进）
- **视频时长缩短**：3-5 条，每条 15-25s，总时长 60-90s

### 排序维度参考

| 维度 | 权重 | 说明 |
|------|------|------|
| 影响范围 | 高 | 全行业 vs 单一公司 |
| 新鲜度 | 高 | 首次发布 vs 后续进展 |
| 实用性 | 中 | 对用户/开发者有直接影响 |
| 话题性 | 中 | 是否引发广泛讨论 |
| 争议性 | 低 | 有争议但不低俗 |

### 三段式脚本模板：「What—So What—Now What」3W 模型

> **学术出处**：What—So What—Now What（简称 "3W" 分析法），哈佛商学院、麦肯锡内部复盘常用框架。在商业咨询、情报分析、学术研究中广泛使用。

#### 白话版 → 专业术语对照

| 白话版 | 3W 模型 | 核心目的 |
|--------|---------|----------|
| 发生了什么 | **What**（事实层） | 客观描述事件本身，剥离情绪和猜测 |
| 影响啥 | **So What**（含义层） | 分析连锁反应、风险与机遇 |
| 值不值得跟进 | **Now What**（行动层） | 基于影响推导决策建议和优先级 |

#### 职场变体（按场景选用）

| 变体 | 适用场景 |
|------|---------|
| 情境—影响—应对（Situation—Impact—Response） | 危机公关 |
| 事件—洞察—行动（Event—Insight—Action） | 数据运营 |
| 事实—判断—决策（Fact—Judgment—Decision） | 投资分析 |

#### 脚本模板

```
Hook: {核心事件，一句话抓住注意力}
What（发生了什么）: {关键事实，2-3句}
So What（影响啥）: {对行业/用户的影响，1-2句}
Now What（值不值得跟进）: {结论/建议，1句}
```

## 适用场景

- 新闻量大但质量参差不齐的日子
- 周报模式下需要精炼
- 用户时间有限，只想看精华
- 正式汇报/研报中引用时，可直接标注「采用 3W 分析法」提升专业感
