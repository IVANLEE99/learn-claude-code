# 产品需求文档 (PRD)

## 项目信息

| 项目 | 内容 |
|------|------|
| 项目名称 | Check-In-Mini-Program |
| 项目类型 | 微信小程序 |
| 版本 | MVP v1.0 |
| 更新日期 | 2026-05-12 |

## 项目概述

一个简洁的每日打卡签到微信小程序，帮助用户养成每日签到习惯，记录打卡历史，并显示连续打卡天数。

## 目标用户

- 需要养成每日签到习惯的微信用户
- 年龄段：18-45岁
- 设计风格：简洁、清新

## 功能列表

### F01: 微信登录

| 项目 | 内容 |
|------|------|
| 功能编号 | F01 |
| 功能名称 | 微信登录 |
| 优先级 | P0 (核心) |

**用户故事：**
- 作为用户，我希望通过微信一键登录，以便快速开始使用打卡功能
- 作为用户，我希望登录后能保持登录状态，无需每次重新登录

**验收标准：**
1. 用户点击"微信登录"按钮，调用 wx.login 获取 code
2. 后端通过 code2Session 换取 openid 和 session_key
3. 后端生成 JWT token 返回给前端
4. 前端存储 token 到本地缓存
5. 新用户自动创建账户

### F02: 每日打卡签到

| 项目 | 内容 |
|------|------|
| 功能编号 | F02 |
| 功能名称 | 每日打卡签到 |
| 优先级 | P0 (核心) |

**用户故事：**
- 作为用户，我希望每天能一键打卡，以便记录我的签到行为
- 作为用户，我希望看到打卡成功的反馈

**验收标准：**
1. 首页显示"打卡"按钮
2. 点击后调用后端 API 记录签到
3. 每天只能打卡一次，重复打卡提示"今日已打卡"
4. 打卡成功后显示连续打卡天数
5. 打卡按钮状态变化（已打卡/未打卡）

## 非功能性需求

### 性能需求
- 首页加载时间 < 2秒
- 打卡操作响应时间 < 1秒
- 列表页支持分页加载

### 安全需求
- 用户数据加密存储
- 接口必须鉴权
- openid 不暴露给前端
- 接入微信内容安全审核（如涉及 UGC）

### 兼容性需求
- 支持 iOS 和 Android
- 最低支持微信版本 7.0+
- 适配主流屏幕尺寸

---

## 微信小程序特有需求

| 需求项 | 说明 |
|--------|------|
| 登录方式 | 微信登录（wx.login + code2Session） |
| 订阅消息 | 暂不使用（MVP阶段） |
| 微信支付 | 不涉及 |
| UGC 内容 | 暂无用户生成内容 |
| 目标用户群体 | 18-45岁，简洁清新风格 |
| 分包加载 | 暂不需要（页面少于10个） |
