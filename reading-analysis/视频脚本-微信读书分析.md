## 二、什么是微信读书 Skill（0:45 - 2:00）

### 画面
屏幕录制：Claude Code 终端界面 + 微信读书 Skill 安装过程

### 文案

先说说这个东西是什么。

微信读书 Skill 是一个 Claude Code 的扩展插件，装上之后，AI 就能直接连接你的微信读书账号，读取你的书架、笔记、划线、阅读时长等数据。

它能做什么？

| 功能 | 说明 |
|------|------|
| 查阅书架 | 看你书架里有多少书，最近在读什么 |
| 阅读统计 | 总时长、日均阅读、偏好分类 |
| 笔记划线 | 导出你的划线和想法 |
| 书籍搜索 | 在书城搜书，获取评分信息 |
| 推荐好书 | 基于你的阅读偏好推荐书籍 |

一句话：让 AI 成为你的阅读搭档。

安装方式也很简单——

### 画面
屏幕录制：终端输入安装命令

```bash
# 自动安装
# 把这段话发给 AI 助手即可
下载 https://cdn.weread.qq.com/skills/weread-skills.zip 安装 skill
```

或者手动安装：

```bash
mkdir -p ~/.claude/skills/weread
cd ~/.claude/skills/weread
curl -sL "https://cdn.weread.qq.com/skills/weread-skills.zip" -o /tmp/weread-skills.zip
unzip -o /tmp/weread-skills.zip -d /tmp/weread-skills-extracted
cp /tmp/weread-skills-extracted/weread-skills/*.md .
```

装好之后，还需要一个 API Key 去连接你的微信读书账号。

### 画面
屏幕录制：打开 weread.qq.com，展示获取 API Key 的页面

去 weread.qq.com 登录，获取你的 API Key，然后设置环境变量：

```bash
export WEREAD_API_KEY=wrk-xxxxxxxx
```

好了，准备工作完成。

### 第四部分：信息茧房（重点）

AI 识别出了 5 个认知盲区：

### 画面
屏幕录制：展示 5 个茧房的分析

**茧房 1：叙事思维主导，缺乏科学思维**

书架几乎全是故事和叙事——小说、散文、传记、历史故事。缺少科学方法论、数据思维、进化论、认知科学。

**风险**：倾向于用"故事"理解世界，但世界很多问题不是故事能解释的。可能低估概率、忽视统计、过度依赖个案。

**茧房 2：中国视角为主，缺少全球视野**

历史书几乎全是中国史，世界史只有 2 本。缺少欧美历史、全球化视角、非西方文明。

**风险**：对中国有深刻理解，但对世界其他地区的理解可能停留在表面。

**茧房 3：感性丰富，理性薄弱**

读了大量文学和情感类书籍，但经济学、政治学、社会学、心理学的严肃著作很少。

**风险**：可能对社会运行的底层逻辑（权力、市场、制度）缺乏系统理解。

**茧房 4：个人成长类停留在鸡汤层**

个人成长书籍大多是励志型，缺少深度思维训练。

**风险**：可能用"努力就能成功"的框架理解一切，忽视结构性因素。

**茧房 5：缺少"反舒适区"的阅读**

阅读整体偏舒适和愉悦——经典文学、武侠、漫画。缺少让人"不舒服"的书。

**风险**：阅读变成了一种"确认偏误"——不断读自己喜欢的类型，而非拓展认知边界。
