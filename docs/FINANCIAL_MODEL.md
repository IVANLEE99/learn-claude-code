## 七、风险提示

1. **收入不确定性**：外包收入取决于订单获取，存在较大波动
2. **时间投入超支**：项目沟通、修改可能消耗更多时间
3. **竞争压力**：新手初期可能需要降价接单，影响时薪
4. **现金流风险**：如果前2周没有订单，现金流将非常紧张

**建议**：严格控制时间投入，优先选择沟通成本低的项目，避免陷入无限修改的陷阱。
